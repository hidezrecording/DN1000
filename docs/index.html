01 · The machine

Built for the road.
Loved in the studio.

In the 1970s, the finest sound reinforcement consoles were built fully discrete: transformer-coupled inputs, transistor gain stages, inductor EQ and power supplies with real muscle. Engineers began pulling channels out of those live rigs and racking them in studios, where they became first-call favorites. The DN1000 is one of those channels, recreated at the component level: an input transformer, three discrete transistor stages, and three switchable outputs, with power-supply sag, thermal drift and analog hiss completing the vintage behavior.

Two discrete channels

Fully discrete left and right paths with per-channel component tolerances, mic/line inputs, low and high cuts, and optional stereo link.

Three output irons

The original-style transformer, a hi-fi Cinemag, and a nickel-iron design with triode gain and beam-tetrode output. Three flavors, one switch.

Alive, not static

Shared power-supply sag couples the channels, bias memory makes repeated peaks behave like real transistors.

macOS installation

Download the latest Mac installer, then follow these steps if Gatekeeper or your DAW blocks DN1000.

Download Mac installer
  1. Run the installer. Download and open the .pkg file. It removes any previous DN1000 build automatically.
  2. Approve it in Gatekeeper if macOS blocks it. Go to System Settings → Privacy & Security, scroll down, then click “Open Anyway.”
  3. Clear quarantine if your DAW still refuses the plug-in. Open Terminal and run the AU command below. For VST3, use the second command.xattr -cr ~/Library/Audio/Plug-Ins/Components/DN1000.componentxattr -cr ~/Library/Audio/Plug-Ins/VST3/DN1000.vst3
  4. Rescan plug-ins in your DAW, then load DN1000 as an AU or VST3.
